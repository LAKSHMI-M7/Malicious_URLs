Technical Overview

Our detection engine utilizes a Random Forest Classifier trained on over 650,000 URLs. The model analyzes lexical features and structural patterns to categorize links into four categories:

  • Benign: Safe, legitimate websites.
  • Defacement: Websites whose content has been maliciously altered.
  • Phishing: Fraudulent sites designed to steal user credentials.
  • Malware: Sites hosting malicious software or exploits.

About the Project

This application was developed as a cybersecurity showcase to demonstrate the power of Machine Learning in threat detection. It aims to provide a fast, reliable, and user-friendly interface for checking link safety.
